# 💫 About Me:
I'm Pratikshya Parida a passionate Data Science and AI professional based in Bengaluru, India, with a versatile background spanning data analytics, machine learning workflows, and software quality engineering. I specialize in designing production-ready Generative AI solutions, including Retrieval-Augmented Generation (RAG) pipelines, semantic search applications, and autonomous multi-step agents using LangChain and LangGraph.My technical toolkit features robust Python development, SQL, vector databases (ChromaDB, FAISS), and model evaluation frameworks (Ragas, LangSmith). Backed by experience in deploying models via FastAPI and Docker—alongside a strong foundation in data quality and rigorous validation—I am eager to apply innovative AI and analytics to enterprise and global supply chain challenges.
